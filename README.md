# GET UPSTAIRS — Terjemahan Bahasa Indonesia

Mod tidak resmi yang menerjemahkan game horor **[GET UPSTAIRS](https://joetheitchpro.itch.io/get-upstairs)** karya Joseph Mularczyk (JoeTheItchPro) ke dalam Bahasa Indonesia.

> ⚠️ Mod ini **tidak berisi game**. Yang dibagikan hanya file patch (xdelta), jadi kamu tetap harus membeli/mengunduh game aslinya di itch.io.

## Cara Pasang

1. Beli/unduh **GET UPSTAIRS** dari itch.io.
2. Unduh rilisan mod ini, lalu extract semua isinya ke folder game (folder yang berisi `GET UPSTAIRS.exe`).
3. Jalankan `PASANG.bat`.
4. Selesai — jalankan game seperti biasa.

`PASANG.bat` otomatis membuat backup file bahasa Inggris asli sebelum menimpanya, jadi proses ini aman untuk dibatalkan.

## Cara Hapus / Kembali ke Bahasa Inggris

Jalankan `HAPUS.bat`. File asli akan dikembalikan dari backup.

## Catatan Kompatibilitas

Patch ini dibuat dengan `xdelta3` dan hanya cocok untuk versi game yang disebut di atas. Jika game sudah diperbarui ke versi lain, `PASANG.bat` akan gagal dan menampilkan pesan error alih-alih merusak file game.
